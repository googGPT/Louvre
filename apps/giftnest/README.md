# GiftNest

Idées de cadeaux, budgets et occasions, gratuit, sans compte et hors ligne.

- Personnes avec budget facultatif : dépensé (cadeaux achetés ou offerts), reste, alerte de dépassement — y compris « dépassé si toutes les idées sont achetées ».
- Occasions ponctuelles ou annuelles (anniversaires, Noël) avec compte à rebours ; un 29 février est fêté le 28 les autres années.
- Cadeaux rattachés à une personne et, au choix, à une occasion ; statut idée → acheté → offert d'un geste ; filtre par personne.
- Supprimer une personne supprime ses cadeaux ; supprimer une occasion conserve les cadeaux, sans occasion.
- Sauvegarde JSON validée (références croisées vérifiées) ; protection si le stockage local est illisible.

Tests : `bash scripts/test_app.sh giftnest`.

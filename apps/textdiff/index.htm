Les changements sont alignés selon une plus longue sous-séquence commune (LCS). Plusieurs alignements peuvent être également valides, notamment pour des lignes répétées. Les changements de lignes affichent les numéros d’origine et d’arrivée. La similarité est une mesure fondée sur les unités sélectionnées, pas une évaluation du sens. Le TXT est un rapport de lecture, pas un patch Git applicable.

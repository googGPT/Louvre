01 · SAISIE

Évaluer une option

Chaque ligne est une note donnée à une option sur un critère. Pour comparer deux options, renseignez tous les critères pour chacune avec les mêmes poids.

Important : une note de 10 signifie toujours « meilleur ». Sur le prix, un tarif moins cher reçoit donc une note plus élevée.

La sauvegarde locale ne peut pas être lue. Exportez la copie brute ; une nouvelle sauvegarde ne l'écrasera pas sans confirmation de restauration.

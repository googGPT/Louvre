# ShiftLedger — Louvre App Factory vague 2

Journal de services et estimation de rémunération selon le taux, le seuil d'heures normales et le multiplicateur saisis. Traite les nuits (passage de minuit), les pauses non rémunérées, la somme par service, le coût grossier en centimes, l'export CSV et les sauvegardes JSON validées. Les dates et règles sont déclaratives ; **ce n'est pas un bulletin de paie ni un calcul juridique certifié**.

Différenciation des 27 produits : RoundPlan gère entraînement fractionné, MileageBook suit kilomètres, aucun n'estime les heures nettes et la rémunération déclarative. Aucune API payante, aucun cloud et PWA gratuite sous quotas GitHub.

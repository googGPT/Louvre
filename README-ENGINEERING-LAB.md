# Louvre — Première expérimentation d'ingénierie

Le dossier [`labs/reservation-lab/`](labs/reservation-lab/) contient une application de démonstration Next.js/TypeScript avec une interface, deux endpoints JSON et des tests du domaine.

Cette expérience est **séparée de la bibliothèque documentaire**. Elle montre comment combiner plusieurs fiches existantes pour développer un exemple original, vérifier ce qui marche et constater les limites. Ce n'est pas une application de réservation utilisable en production.

Consulter la [documentation du laboratoire](labs/reservation-lab/README.md) pour lancer l'application et voir les références détaillées aux ouvrages.
